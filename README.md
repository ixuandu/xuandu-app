## 安装

1. 用手机浏览器打开上面的下载链接（**不要在微信里直接点**，见下方「常见问题」）。
2. 下载完成后点击安装包。
3. 首次安装会提示「未知来源应用」——允许浏览器/文件管理器安装应用即可。
4. 若提示「已有更高版本」，说明手机里装的是更新版本，不必降级。

## 常见问题

**在微信里点下载没反应 / 提示"已停止访问该网页"**
微信内置浏览器禁止直接下载 APK。点右上角 **···** → 「在浏览器打开」，再下载。

**安装被拦截，提示"未经安全检测"**
国产 ROM 的安全中心会拦自签名/非商店来源的包。到「设置 → 安全 → 安装未知应用」里，给浏览器或文件管理器放行即可。

**iOS 有吗？**
暂未上架 App Store，iOS 版正在准备中。

**能自动升级吗？**
可以。App 内建了升级检查（连接管理端后自动比对版本），也可在 App 内手动「检查更新」。本页的安装包只用于**首次安装**。
